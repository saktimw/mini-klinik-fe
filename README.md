## Mini Klinik V.1
Aplikasi Management Klinik Kesehatan sederhana yang dibuat untuk memenuhi kebutuhan klinik / praktek mandiri.

### Fitur yang sedang dikembangkan :

* Pendaftaran Pasien
* Pengisian Rekam medis sederhana ( Pemeriksaan TTV & Anamnesis )
* Billing / Pembayaran 

## Developer Guide

### Struktur Folder & Konfigurasi :
* **app / globas.css :** Custom styling tailwindcss yang dapat dire-use 
* **assets :** semua asset aplikasi ( gambar,icon,font, dll. )
* **package.json :** semua library, dependency yang dibutuhkan oleh aplikasi. 

Untuk menjalankan aplikasi silahkan ketikan perintah berikut :

`npm run dev`
